# Semi Sector Decoupling Monitor

**Real-Time AI Compute vs Semi Equipment Divergence Tracker**

## What It Is

A self-contained HTML dashboard that tracks the single most important signal in the AI trade: when NVDA holds while semi equipment/storage crashes, that's a decoupling signal. When everything moves together, it's a broad sector rotation.

## Features

- **20-Ticker Coverage**: NVDA, AVGO, MRVL (compute) + AMAT, LRCX, KLAC (equipment) + SNDK, MU, STX (storage) + macro (SPY, QQQ, IWM, TLT, GLD, US10Y, VIX)
- **Decoupling Score (0-10)**: Proprietary algorithm measuring compute vs equipment divergence
- **Pattern Detection**: Automatic decoupling, recoupling, and regime shift identification
- **Alert Thresholds**: Configurable alerts for each regime type
- **Zero Dependencies**: Runs in any browser, no install, no API keys

## How to Use

1. Open `semi_decoupling_dashboard.html` in any browser
2. Click "Refresh Data" to pull latest prices
3. Watch the Decoupling Score for regime signals
